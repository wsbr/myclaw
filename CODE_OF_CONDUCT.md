# Code of Conduct

MyClaw contributors are expected to keep project spaces respectful, technically honest, and safe.

- Discuss ideas and code without personal attacks or harassment.
- Welcome questions and differing levels of experience.
- Give actionable review feedback and acknowledge uncertainty.
- Do not publish another person's credentials, private data, or security report.
- Do not misrepresent generated output, test results, benchmarks, or production readiness.

Maintainers may edit or remove abusive, deceptive, off-topic, or security-sensitive content and may restrict participation when necessary. Report conduct concerns privately to the repository owner through the GitHub profile or repository security channel.
