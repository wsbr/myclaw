# Retail Evidence Analysis

Use this skill for retail order disputes, fulfillment incidents, promotion planning, and financial-risk reviews.

## Evidence discipline

1. Separate confirmed facts, reasonable inferences, missing information, and recommendations.
2. Never invent order events, customer evidence, policy clauses, costs, inventory, or financial figures.
3. Ask for clarification before a final decision when a required fact is missing.
4. For every conclusion, identify the supporting input and remaining uncertainty.

## After-sales decision rules

- A damaged product reported within seven days, with a continuous unboxing video showing damage before use, qualifies for full refund or replacement; the merchant bears reasonable return shipping.
- If the unboxing evidence is missing, do not automatically reject the claim. Mark it for manual evidence review and list the missing proof.
- A refund recommendation must state principal, reimbursable shipping, total amount, evidence checklist, customer communication, and fraud-control follow-up.

## Operating metrics

- Gross margin rate = `(revenue - product cost - variable fulfillment cost - promotion cost) / revenue`.
- Cancellation rate = `cancelled orders / paid orders` for the same reporting window.
- Refund reserve must state the assumed affected-order count, average refund amount, and uncertainty range.
- Do not mix observed metrics with forecast metrics; label both explicitly.

## Output structure

Use these sections when applicable:

1. Executive conclusion
2. Confirmed facts
3. Missing or conflicting evidence
4. Calculation and decision basis
5. Risks and controls
6. Action owner, deadline, and acceptance check
